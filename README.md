# Vidferry

macOS 视频下载器：粘贴链接，或在内置浏览器中发现正在播放的视频，选择画质或只提取音频后多线程下载。

## 下载与安装

系统要求：macOS 26 及以上，Apple Silicon。界面目前只有简体中文。

1. 下载 [Vidferry.zip](https://github.com/leadead/Vidferry-Releases/releases/latest/download/Vidferry.zip)（[所有版本](https://github.com/leadead/Vidferry-Releases/releases)）
2. 解压后把 Vidferry 拖入「应用程序」

安装包已通过 Apple 公证。

## 更新

App 会自动检查更新，也可以在 App 菜单中点「检查更新…」。

## 隐私

Vidferry 不采集、不上传任何数据。

## 使用须知

请只下载你有权保存的内容。Vidferry 不支持带 DRM 保护的视频。

## 第三方组件

Vidferry 内置 FFmpeg（LGPL 2.1 或更高版本）、yt-dlp（Unlicense）、Deno（MIT）和 Sparkle（MIT）。版本号、FFmpeg 的源码地址和完整许可证见 App 包内的 `Contents/Resources/ThirdPartyLicenses.txt`。

本仓库只用于发布安装包，Release 页面的 Source code 压缩包里也只有这份说明。Vidferry 本身不开源：官方版本可免费下载使用，不得再分发或修改；内置的第三方组件仍按各自的许可证授权。
